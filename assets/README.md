# Sanitized Screenshots

Add only reviewed copies of screenshots to this folder. Suitable evidence includes:

- The final simulated email layout with sender and recipient addresses hidden.
- The lab login interface with the assigned hostname hidden.
- The running service and successful HTTP response with identifiers hidden.
- The HTTP 404 response for the attempted record-file path.

Remove personal addresses, student IDs, assigned network details, session tokens, and captured credentials. Do not include credential-log screenshots or the private course report.

Crop or redact copies, preserving private originals elsewhere. Check that the text remains readable after inserting each image into the README.
